2. How Token Swaps Work

Traditional Exchange (Centralized):

You → Give tokens to exchange → Exchange holds them → Gives you other tokens
Problem: You must trust the exchange


DEX (Decentralized):

You → Smart contract holds tokens in pool → You swap directly from pool
Benefit: No middleman, you stay in control


Key Concept - Liquidity Pool: A smart contract that holds two tokens (like ETH and USDT) so people can trade between them.

---

3. Understanding Liquidity Pools

What is a Liquidity Pool? Think of it as a pot of two tokens that people can trade against.

Example Pool:

Pool contains:
├── 100 ETH
└── 200,000 USDT

Current price: 1 ETH = 2,000 USDT


How Swapping Works:

1. User wants to buy 1 ETH
2. They add USDT to the pool
3. They remove ETH from the pool
4. Price adjusts automatically based on supply

The Magic Formula: x × y = k

This formula keeps the pool balanced:

* x = Amount of Token A (ETH)
* y = Amount of Token B (USDT)
* k = Constant number that never changes

Simple Example:

Starting Pool:
100 ETH × 200,000 USDT = 20,000,000 (this is k)

Someone buys 1 ETH:
- Pool now has: 99 ETH
- To keep k the same: 99 × ? = 20,000,000
- ? = 202,020 USDT
- User must add: 202,020 - 200,000 = 2,020 USDT

New Pool:
99 ETH × 202,020 USDT = 20,000,000 (k stays same!)


Key Point: The more you buy, the higher the price goes (because you're draining the pool).

4. Building a Simple Swap Contract

What We'll Build: A contract where users can:

1. Add liquidity (deposit two tokens)
2. Swap Token A for Token B
3. Swap Token B for Token A

Complete Code:

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

interface IERC20 {
    function transfer(address to, uint256 amount) external returns (bool);
    function transferFrom(address from, address to, uint256 amount) external returns (bool);
    function balanceOf(address account) external view returns (uint256);
}

contract SimpleSwap {
    // The two tokens in our pool
    IERC20 public tokenA;
    IERC20 public tokenB;
    
    // How many tokens are in the pool
    uint256 public reserveA;
    uint256 public reserveB;
    
    event LiquidityAdded(address indexed provider, uint256 amountA, uint256 amountB);
    event Swapped(address indexed user, string direction, uint256 amountIn, uint256 amountOut);
    
    constructor(address _tokenA, address _tokenB) {
        tokenA = IERC20(_tokenA);
        tokenB = IERC20(_tokenB);
    }
    
    // Add liquidity to the pool
    function addLiquidity(uint256 amountA, uint256 amountB) external {
        require(amountA > 0 && amountB > 0, "Amounts must be greater than 0");
        
        // Transfer tokens from user to this contract
        tokenA.transferFrom(msg.sender, address(this), amountA);
        tokenB.transferFrom(msg.sender, address(this), amountB);
        
        // Update reserves
        reserveA += amountA;
        reserveB += amountB;
        
        emit LiquidityAdded(msg.sender, amountA, amountB);
    }
    
    // Swap Token A for Token B
    function swapAforB(uint256 amountAIn) external {
        require(amountAIn > 0, "Amount must be greater than 0");
        require(reserveB > 0, "No liquidity");
        
        // Calculate how much Token B user gets
        // Formula: amountOut = (reserveB * amountIn) / (reserveA + amountIn)
        uint256 amountBOut = (reserveB * amountAIn) / (reserveA + amountAIn);
        
        require(amountBOut > 0, "Insufficient output amount");
        require(amountBOut < reserveB, "Not enough liquidity");
        
        // Transfer tokens
        tokenA.transferFrom(msg.sender, address(this), amountAIn);
        tokenB.transfer(msg.sender, amountBOut);
        
        // Update reserves
        reserveA += amountAIn;
        reserveB -= amountBOut;
        
        emit Swapped(msg.sender, "A->B", amountAIn, amountBOut);
    }
    
    // Swap Token B for Token A
    function swapBforA(uint256 amountBIn) external {
        require(amountBIn > 0, "Amount must be greater than 0");
        require(reserveA > 0, "No liquidity");
        
        // Calculate how much Token A user gets
        uint256 amountAOut = (reserveA * amountBIn) / (reserveB + amountBIn);
        
        require(amountAOut > 0, "Insufficient output amount");
        require(amountAOut < reserveA, "Not enough liquidity");
        
        // Transfer tokens
        tokenB.transferFrom(msg.sender, address(this), amountBIn);
        tokenA.transfer(msg.sender, amountAOut);
        
        // Update reserves
        reserveB += amountBIn;
        reserveA -= amountAOut;
        
        emit Swapped(msg.sender, "B->A", amountBIn, amountAOut);
    }
    
    // Preview: How much will I get if I swap?
    function getSwapAmount(uint256 amountIn, bool swapAforB) external view returns (uint256) {
        if (swapAforB) {
            return (reserveB * amountIn) / (reserveA + amountIn);
        } else {
            return (reserveA * amountIn) / (reserveB + amountIn);
        }
    }
    
    // View current pool status
    function getReserves() external view returns (uint256, uint256) {
        return (reserveA, reserveB);
    }
}

// First approve the swap contract to use your tokens
tokenA.approve(swapContractAddress, 1000);

swapContract.addLiquidity(1000, 2000);
// Now pool has: 1000 Token A and 2000 Token B


Step 4: Swap Tokens

// User wants to swap 10 Token A for Token B

// Contract calculates: (2000 * 10) / (1000 + 10) = 19.8 Token B

6. Frontend Integration

Simple Swap Interface:

// Connect to contracts
const tokenA = new ethers.Contract(tokenAAddress, erc20ABI, signer);
const tokenB = new ethers.Contract(tokenBAddress, erc20ABI, signer);
const swap = new ethers.Contract(swapAddress, swapABI, signer);

// Get swap preview
async function getSwapPreview(amountIn, isTokenA) {
    const amount = ethers.utils.parseEther(amountIn);
    const amountOut = await swap.getSwapAmount(amount, isTokenA);
    return ethers.utils.formatEther(amountOut);
}

// Add liquidity
async function addLiquidity(amountA, amountB) {
    // Approve both tokens
    const txA = await tokenA.approve(swapAddress, ethers.utils.parseEther(amountA));
    await txA.wait();
    
    const txB = await tokenB.approve(swapAddress, ethers.utils.parseEther(amountB));
    await txB.wait();
    
    // Add liquidity
    const tx = await swap.addLiquidity(
        ethers.utils.parseEther(amountA),
        ethers.utils.parseEther(amountB)
    );
    await tx.wait();
    alert("Liquidity added!");
}

// Execute swap
async function executeSwap(amountIn, isTokenA) {
    // Approve token
    const token = isTokenA ? tokenA : tokenB;
    const approveTx = await token.approve(swapAddress, ethers.utils.parseEther(amountIn));
    await approveTx.wait();
    
    // Swap
    const swapTx = isTokenA 
        ? await swap.swapAforB(ethers.utils.parseEther(amountIn))
        : await swap.swapBforA(ethers.utils.parseEther(amountIn));
    
    await swapTx.wait();
    alert("Swap successful!");
}

// Display pool info
async function displayPoolInfo() {
    const reserves = await swap.getReserves();
    console.log("Token A Reserve:", ethers.utils.formatEther(reserves[0]));
    console.log("Token B Reserve:", ethers.utils.formatEther(reserves[1]));
    
    const price = reserves[1] / reserves[0];
    console.log("Current Price: 1 Token A =", price, "Token B");
}

7. Understanding Price Impact

What is Price Impact? When you make a large trade, you change the pool balance significantly, affecting the price.

Example:

Pool: 100 ETH × 200,000 USDT

Small trade (1 ETH):
- Get ~2,000 USDT
- Price impact: ~0.5%

Large trade (10 ETH):
- Get ~18,182 USDT (not 20,000!)
- Price impact: ~9%
- You get worse price because you're draining the pool


Key Learning: Bigger trades = worse prices in small pools!

---

8. Important Concepts

Slippage:

* The difference between expected price and actual price
* Happens because price changes during your transaction
* Solution: Set "minimum amount out" to protect yourself

Liquidity:

* More liquidity = better prices for traders
* More liquidity = less price impact
* Liquidity providers earn fees (0.3% per trade)

Why Add Liquidity?

* Earn fees from every trade
* Help the protocol function
* Get trading fee share proportional to your contribution

🔗 Quick Reference

Swap Formula:

Output Amount = (Reserve Out × Amount In) / (Reserve In + Amount In)


Price Calculation:

Price = Reserve B / Reserve A


Example Calculation:

Pool: 100 Token A, 200 Token B
Input: 10 Token A

Output = (200 × 10) / (100 + 10)
       = 2000 / 110
       = 18.18 Token B

🆘 Common Issues

"Insufficient liquidity" error:

* Pool doesn't have enough tokens
* Add more liquidity first

"Insufficient output amount" error:

* Slippage too high
* Try smaller trade amount

Swap not working:

* Check you approved tokens first
* Verify you have enough balance
* Ensure pool has liquidity

💡 Tips for Success

1. Start Small: Test with small amounts first
2. Always Approve First: Approve tokens before swapping
3. Check Reserves: Make sure pool has liquidity
4. Test Both Directions: Swap A→B and B→A
5. Monitor Gas: Swaps cost gas, factor that in
